# ShiftLens

A calendar for people who work shifts. Set a cycle once, then only edit the days that change.

Package: `com.ShiftLensMNG.ShiftLens`

Remote config: [R252.json](https://api2.blwsmartware.net/R252.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product | Type |
| --- | --- |
| `sl_pack_1` … `sl_pack_10` | Consumable coins |
| `sl_remove_ads` | Non-consumable |
| `sl_pro` | Non-consumable, more than 8 schedules |

Cycles, one-day changes, and reminders stay on this phone. ShiftLens does not upload a rota.
